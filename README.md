# gravipanda

## What is the game about
You're a panda who really likes golden bamboo so you climb lots of platforms to try and find some. Oh, you can also reverse gravity at will.

## How to play locally
There is a web version available at [itch.io](https://zakkbob.itch.io/gravipanda)

## Controls:
| button|action |
|--|--|
| a / d / arrows | move left/right |
|space / up arrow | jump |
|s / down arrow | reverse gravity|
